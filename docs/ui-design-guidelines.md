# UI デザインガイドライン

ブレインゴースト全画面に共通する UI トークン・サイズ規約。Godot 4 の `theme_override_font_sizes/font_size` および `custom_minimum_size` を中心に定義する。

ターゲットビューポート: **720×1280**（縦持ち基準）。Android 実機 (moto g66j / 1080×2400) や DPR 違いの端末でも視認性を確保することが目的。

## 最低文字/アイコンサイズ規約

ユーザレビュー (2026-05-16) で「全体的に文字が小さい」「ホームの設定アイコンと全ゲーム一覧が見えない」と指摘されたため策定。Material Design (16dp+ body, 14dp+ caption) と Apple HIG (17pt+ body) を参考に、720×1280 を 1.0 倍として換算した最低値を定める。

### 文字サイズ最低値

2026-05-16 のユーザレビューで「直前規約値でもまだ小さい」と再フィードバックを受け、ベースラインを 1 段階引き上げた版（v2）。

| 用途 | 例 | **最低値 (px)** | 推奨 (px) |
|---|---|---|---|
| 本文・カード説明 | ゲーム概要文 | **24** | 26 |
| ナビラベル | 脳トレ/分析/ホーム/アワード | **22** | 24 |
| HUD 補助文言 | "LIVE SYNC"・「自分」「ゴースト」 | **20** | 22 |
| HUD 内スコア値 | "0" / "—" | **26** | 28 |
| 装飾チップ・タグ | ATTENTION / CALCULATION | **18** | 20 |
| ボタン文言・テキストリンク | 「全ゲーム一覧 ›」「もう一度」 | **28** | 32 |
| セクションヘッダ | 「今日のチャレンジ」 | **32** | 36 |
| ディスプレイ大数値 | 結果画面スコア | **44** | 56 以上 |

**規約原則**:

- 16px を下回るテキストは原則禁止。装飾チップなど例外も 16px が下限
- ユーザが読む情報（本文・ボタン・ラベル）は 18px 以上
- タップ可能なテキストリンクは 24px 以上（押し間違いを防ぐため）
- スコア値（HUD 内の数値）は周囲ラベルより必ず大きく、22px 以上

### アイコンサイズ最低値

| 用途 | 例 | **最低値 (px)** | 推奨 (px) |
|---|---|---|---|
| 単独アクションアイコン | Settings / Back | **44** | 48 |
| ナビバーアイコン | Bottom Nav アイコン | **40** | 44 |
| 行内アイコン | HBox の小アイコン | **24** | 28 |
| インラインデコレーション | "↻" "‹" などの記号 | **24** | 28 |

Material Symbols フォント (`MaterialSymbolsRounded.ttf`) を使う場合、見かけのウェイトが細いので **テキスト本文より 4px 大きく** を目安にする。

### タップ可能要素

| 用途 | **最低高さ (px)** | 推奨 |
|---|---|---|
| Button / TextureButton | **56** | 64 |
| ナビバー内 1 タブ | **64** | 72 |
| 行内 IconButton | **48** | 56 |

Material Design の 48dp / Apple HIG の 44pt に揃える。`custom_minimum_size = Vector2(0, 48)` を最低値とすること。

## アイコンアセット

### アプリアイコン

正式アプリアイコン: `assets/icons/game_icon.png`（猫耳キャラ + グロー脳 / Reigal Labs オリジナル）

- `project.godot` の `config/icon` で参照
- Android: `export_presets.cfg` の `launcher_icons/main_192x192` 等で参照
- 旧 `res://icon.svg` (Godot デフォルト) は使用禁止

### マスコット

`assets/characters/catboy_electric.png`（CLAUDE.md 「mascot is catboy」参照）が正式マスコット。
GhostChibi（吹き出し横）/ 比較カード YouAvatar 等で利用。

## 既存テーマ（default_theme.tres）

`mc_*` (Midnight Cat) 系の theme_type_variation はこの規約に従って定義済み:

- `mc_h1`: 44px (大見出し)
- `mc_h1_lg`: 56px (特大見出し)
- `mc_h2`: 32px (中見出し)
- `mc_step_body` / `mc_caption`: 18-22px
- `mc_cta_glow`: 38px (CTA ボタン)
- `mc_back_btn`: 16px → **要見直し** (テキストリンクは 24px 規約のため）

新しい画面を作る際は、まず `mc_*` バリエーションが使えないか確認してから theme_override_font_sizes で個別指定する。

## 守らない例外

以下のケースは規約より小さくしてよい:

1. **常にユーザに見せるわけではない補助テクスト**（デバッグ表示・極小キャプション）
2. **画面遷移前のスプラッシュ表示**（ローディング進捗等）
3. **物理的に縦が足りないコンテナ**（ただし設計を見直す前提）

例外を採用する際は、コメントで理由を明記すること。
