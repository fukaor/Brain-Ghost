# 競合アプリ UI/UX リサーチ

> ブレインゴースト の UI 設計のための参考資料。機能ではなく**見た目・レイアウト・モバイルアプリらしさ**に焦点。
> 出典: GDD 付録 A（brain_training_gdd.md）
> リサーチ日: 2026-04-10

## サマリ: ブレインゴースト が取り込むべきパターン（TL;DR）

- **白〜オフホワイト背景 + 1〜2 色のアクセント**を基調にする。脳トレ系の和アプリは総じて高彩度背景を避け、白地に青系・緑系アクセント 1 色を柱にする構成が多い。ブレインゴースト も `scripts/utils/color_palette.gd` で白/クリーム背景 + ゴールドまたは緑のアクセントに絞るとモバイルらしさが出る。
- **タイポグラフィは「丸ゴシック・太字・大きめ」**。中高年も含むターゲットのため、Noto Sans JP Bold か M PLUS Rounded 1c あたりを基本にし、数値表示（スコア・脳年齢）は 48〜72pt の極太で画面中央にドンと置く。
- **ホームは「カード縦並び」または「2×3 グリッド」**。ボトムタブ 3〜4 個（ホーム / 結果 / 設定、または + カレンダー）が定番。FAB は使わない（ミニゲームアプリではデイリーチャレンジを大型バナーカードで代替するのが主流）。
- **結果画面は「数値大 → グラフ → シェア/もう一度ボタン」の縦 3 段**。脳年齢を数値で巨大に出し、その下にレーダーチャートや折れ線グラフ、最下段に CTA ボタンを 2 つ並べる構成がテンプレ化している。
- **ネガティブ色（赤）を避け、進捗・達成はスタンプ/バッジで可視化**。毎日脳トレのハンコカレンダーは「アプリを続ける動機」を視覚化する強パターン。ブレインゴースト のストリークに直接適用できる。

## 1. みんなの脳トレ (QQ TSUBASA)

- **Play Store / App Store**: [App Store](https://apps.apple.com/jp/app/%E3%81%BF%E3%82%93%E3%81%AA%E3%81%AE%E8%84%B3%E3%83%88%E3%83%AC/id633246396) / [AndroRank](https://androrank.com/?id=yumekan.android.brain)
- **全体の雰囲気**: シンプル・実直・親しみやすい。華美な演出はなく「中高年でも迷わない」設計。1 プレイ約 30 秒で完結する軽さが UI にも反映され、画面遷移が浅い。
- **カラーパレット**: 白〜ベージュ背景に、青系（ロイヤルブルー〜スカイブルー）をアクセントに使う典型的な和製脳トレ配色。6 種類のトレーニング（観察・記憶・判断・計算・直感・反応）は各ミニゲームごとに色分けされている模様。
- **タイポグラフィ**: 丸ゴシック太字が中心。数値表示（特に脳年齢）は非常に大きい。
- **レイアウト**: ホーム画面は 6 ゲームのアイコン／ボタンをグリッド状（2×3 もしくは縦リスト）で配置し、中央または上部に「脳年齢を測る」の大型ボタンを置く構成が一般的。結果画面は自動でグラフ化される。
- **モバイルらしさの勘所**: タップ対象が極端に大きい。1 画面 1 アクションを徹底し、迷わせない。
- **取り込みポイント**: ホーム画面の「大きな CTA + 6 ゲームのグリッド」はそのまま ブレインゴースト の `scenes/main/home.tscn` の骨格に流用可能。1 プレイ 30 秒の軽さを演出するには、ホームから 2 タップ以内にゲーム開始できる導線が必須。
- **避けるべき点**: 演出が素朴すぎて「無料アプリっぽさ」が強い。ブレインゴースト は同じ骨格のままカード型 UI と微シャドウでワンランク上に見せたい。
- **出典**: [Appliv レビュー](https://app-liv.jp/796315/), [ドットアップス](https://dotapps.jp/product_contents/R8hxO0n7CjoNcIUk), [APPLION](https://applion.jp/%E3%81%BF%E3%82%93%E3%81%AA%E3%81%AE%E8%84%B3%E3%83%88%E3%83%AC/iphone-633246396/)

## 2. 毎日脳トレ (nullhouse)

- **Play Store**: [Google Play](https://play.google.com/store/apps/details?id=info.nullhouse.braintraining&hl=en_US)
- **全体の雰囲気**: 「奇抜でない・派手でない・よく釣り合いのとれた」をそのまま体現。控えめで実用本位。長期継続を前提にした落ち着いたトーン。
- **カラーパレット**: 白背景 + 淡いパステル系アクセント（水色・黄緑・薄橙）。アイコンは円形で、カラフルではあるが高彩度ではない。ダークモード非搭載。
- **タイポグラフィ**: 角ゴシック寄りの太字。見出しと本文のジャンプ率が高い（見出し大 / 本文小）。
- **レイアウト**: ホーム画面は縦スクロールでゲームカードを並べる形式。初期は 3 種類だけ表示され、進捗に応じて順次解放されるため、ロック状態のカードがグレーアウトで並ぶ視覚設計。月次レポート画面・グラフ画面・ランキング画面・ハンコカレンダー画面がタブ的に切り替わる。
- **モバイルらしさの勘所**:
  - **ハンコカレンダー**: 月表示のカレンダー上にクリアした日だけハンコ画像（丸い和風スタンプ）が押される。「今日のマスを埋めたい」という毎日開く動機を視覚化。
  - **段階解放**: 未解放コンテンツを見せて「次これか」と思わせるロック演出。
  - **月次レポート**: 月末にまとめて振り返れる折れ線グラフと強み/弱みの自動分析。
- **取り込みポイント**:
  - ハンコカレンダーは GDD §X にも記載あり → `scenes/ui/stamp_calendar.tscn` の参考そのもの。丸スタンプの押印アニメ（弾む + 押印音）をそのまま再現したい。
  - 月次レポート画面は ブレインゴースト にはないが、ストリーク復活施策として「今月のまとめ」を差し込む余地がある（将来拡張）。
- **避けるべき点**: 解放ロックは数が多すぎるとむしろ萎えるので、ブレインゴースト のミニゲーム 6 種なら全開放ベースで「精度 100%」を別軸として見せる方がよい。
- **出典**: [Google Play](https://play.google.com/store/apps/details?id=info.nullhouse.braintraining&hl=en_US), [APPLION](https://applion.jp/android/app/info.nullhouse.braintraining/), [Appliv](https://app-liv.jp/5343877/), [DigitalHealth 解説](https://appdigitalhealth.com/everyday-brain-training/)

## 3. パズル詰め合わせ (nullhouse)

- **Play Store**: [Google Play](https://play.google.com/store/apps/details?id=info.nullhouse.puzzles&hl=en_US)
- **全体の雰囲気**: 10 種類以上のパズル（数独・2048・ライツアウト・15 パズル・ブロック・マーブルソート等）を 1 アプリに詰め込んだ「コレクション型」。毎日脳トレと同開発者で、デザイン言語を共有している。
- **カラーパレット**: 白ベース + パズルごとの固有色（数独=青、2048=オレンジ等）。コントラストを強く取り、パズル盤面の視認性を最優先。
- **タイポグラフィ**: 角ゴシック太字。数字は等幅・太字で盤面用にチューニング。
- **レイアウト**: ホームはパズル種類のグリッドまたはスクロールリスト。各パズルの中では「難易度選択 → ステージ一覧（格子）→ プレイ」の 3 層が標準。デイリーミッション表示あり。広告はプレイ後表示に限定（プレイ中は出さない）。
- **モバイルらしさの勘所**: タブレット対応で画面サイズに応じたスケーリング。盤面は常に中央配置で、上下に UI（スコア / メニュー）を置く定番構成。
- **取り込みポイント**: 「複数ゲームを 1 アプリに収容」する ブレインゴースト と構造が同じ。ゲーム選択画面のグリッドデザインと、各ゲームの「ルール → プレイ → 結果」テンプレートを参考にできる。広告は「プレイ後 only」という ブレインゴースト のポリシーとも完全一致。
- **避けるべき点**: パズル個別の世界観が薄く、コレクション感はあるがブランド統一感に欠ける。ブレインゴースト は 6 ゲーム共通のフレーム（上部に時間/スコア、下部に固定の戻るボタン）で統一感を出したい。
- **出典**: [Google Play](https://play.google.com/store/apps/details?id=info.nullhouse.puzzles&hl=en_US), [APPLION](https://applion.jp/android/app/info.nullhouse.puzzles/)

## 4. PEAK (Synaptic Labs)

- **Play Store**: [Google Play](https://play.google.com/store/apps/details?id=com.brainbow.peak.app&hl=en_US) / [App Store](https://apps.apple.com/us/app/peak-brain-training/id806223188)
- **全体の雰囲気**: グローバル基準のプレミアム感。ゲーミフィケーション全開で、コーチキャラクター・ワークアウトメタファー・ミニゲーム 45+ 種類。和製アプリと比べて情報密度が高くカラフル。
- **カラーパレット**: 濃紺〜黒に近いダークネイビー背景 + ビビッドなマゼンタ/オレンジ/シアンのアクセント。カテゴリごと（Memory=紫、Focus=青、Problem Solving=緑、Mental Agility=橙、Math=赤、Language=水色、Creativity=黄）に色分けされ、Brain Map も色で識別。カラーブラインド対応設定あり。
- **タイポグラフィ**: 英字サンセリフ太字（Proxima Nova 系）。数値は巨大・中央寄せ。
- **レイアウト**: ホームは「今日のワークアウト」カードを縦スタック表示。ボトムタブに Home / Games / Brain Map / Coach / Profile 等。Brain Map は 7 カテゴリの値をレーダーチャート風の六角形/円グラフで表示し、自分の強み/弱みを一目で可視化。
- **モバイルらしさの勘所**:
  - **ダークテーマ + 高彩度アクセント**で「デジタルっぽさ」を強調。
  - **カード UI + 影 + 角丸**を多用し、物理的な紙カードをめくる感覚。
  - **カテゴリ別の色分け**を徹底しているため、Brain Map やリザルトで脳の特性が直感的に読める。
- **取り込みポイント**:
  - レーダーチャート（`scenes/ui/radar_chart.tscn`）は PEAK の Brain Map が最大のお手本。6 軸固定（GDD の計算/記憶/注意/反射/観察/判断）に PEAK の色分けロジックを当てる。
  - ホームの「今日のワークアウトカード」は ブレインゴースト の「デイリーチャレンジ」カードとしてそのまま使える。
- **避けるべき点**: 情報過多・カラフル過ぎてセルフチャレンジャー（ペルソナ 1: 朝通勤 2 分）には重い。ブレインゴースト はダークテーマではなくライト基調 + カテゴリカラーだけ PEAK 風に拝借する、という採用方針が無難。
- **出典**: [Peak.net 公式](https://www.peak.net/), [Google Play](https://play.google.com/store/apps/details?id=com.brainbow.peak.app&hl=en_US), [Mindtools レビュー](https://mindtools.io/programs/peak-brain-training/), [Common Sense Media](https://www.commonsensemedia.org/app-reviews/peak-brain-training)

## 5. ソルティオ (eMotiv)

- **Play Store**: [Google Play](https://play.google.com/store/apps/details?id=com.eMotiv.Solutio&hl=en_US)
- **全体の雰囲気**: 認知症予防をうたう「医療寄り」のトーン。5 つの認知能力軸をスコアで測定する設計で、ブレインゴースト の「6 軸レーダー」と最も近い思想。
- **カラーパレット**: 未特定（Play Store ページを直接確認できず、レビュー記事が薄い）。想定としては白背景 + 落ち着いた青または緑系アクセント。中高年向けのため高彩度は避けていると推定。
- **タイポグラフィ**: 未特定。中高年向けなので太字・大きめの和文ゴシックである可能性が高い。
- **レイアウト**: 未特定。ただし「5 つの能力軸をスコア化」→ レーダーチャートか 5 本の横棒グラフでの表示が定番構成。
- **モバイルらしさの勘所**: 「認知機能スコア化」「軸ごとの強み/弱み可視化」というコンセプト自体が ブレインゴースト と重なる。
- **取り込みポイント**: 軸数が 5 → ブレインゴースト は 6 軸だが、「個別スコア + 総合スコア」の二層構造は参考になる。レーダーチャートの代替として横棒グラフも検討に値する（レーダーは角度で印象操作しやすいが、棒グラフの方が正確）。
- **避けるべき点**: 「医学的効果を謳う」表現は GDD で禁止事項。ブレインゴースト はエンタメ目的を明記する。
- **出典**: [Google Play](https://play.google.com/store/apps/details?id=com.eMotiv.Solutio&hl=en_US) ※ 詳細未特定

## 6. 数字さがし (jaykeigames)

- **Play Store**: [Google Play](https://play.google.com/store/apps/details?id=tokyo.jaykeigames.suujisagashi&hl=en_US)
- **全体の雰囲気**: 「カラフルでかわいい」を明言するビジュアル重視の単体ゲーム。ブレインゴースト の「数字さがし」ミニゲームと同ジャンル（むしろ直接の参考にすべき）。
- **カラーパレット**: 白または明るい単色背景に、数字ひとつひとつが**赤・青・緑・黄・紫・オレンジ**などの高彩度マルチカラーで描かれる。背景は意図的に無地または淡色に抑え、数字の色と大きさの散らばりを主役にする。
- **タイポグラフィ**: 数字は**丸ゴシック極太**で、サイズもバラバラ（視覚的ノイズを意図的に作ることでゲーム難度を演出）。
- **レイアウト**: ゲーム中は画面全体が盤面（数字の散布）。上部に「お題の数字（探す対象）」と残り時間バー、画面下部は空白か小さな戻るボタンのみ。結果画面で脳年齢を大きく表示。
- **モバイルらしさの勘所**: 「画面全体が盤面」という大胆な使い方。上部に最小限の情報 HUD を固定し、下部の指が被る領域はあえて空ける。
- **取り込みポイント**:
  - ブレインゴースト の `scenes/games/number_search.tscn` の視覚設計は、この数字さがしを**ほぼそのまま下敷き**にしてよい（色は 6〜8 色、サイズは 3 段階程度）。
  - 数字の配置はランダムでなく、見つけにくさを調整するために「色と背景のコントラストを落とす」「近い数字を並べる」などの工夫が必要。
- **避けるべき点**: カラフルさが強すぎると他のゲームと浮く。ブレインゴースト の他 5 ゲームと並べたときのブランドトーンを壊さないよう、背景とフレームは共通化する。
- **出典**: [Google Play](https://play.google.com/store/apps/details?id=tokyo.jaykeigames.suujisagashi&hl=en_US), [APPLION](https://applion.jp/%E8%84%B3%E3%83%88%E3%83%AC!!%E6%95%B0%E5%AD%97%E3%81%95%E3%81%8C%E3%81%97/android-tokyo.jaykeigames.suujisagashi/)

## 7. Brain Test (Unico Studio) — 参考度: 低

- **Play Store / App Store**: [App Store](https://apps.apple.com/us/app/brain-test-tricky-puzzles/id1486214495)
- **全体の雰囲気**: ひっかけ問題系のコミカルパズル。ブレインゴースト とは別ジャンルだが、「演出・雰囲気」だけ参考になる。
- **カラーパレット**: クレヨン風の手描き・パステルカラー。罫線もまっすぐでなく、意図的に歪ませて「小学生のノート」感を出している。
- **タイポグラフィ**: 手書き風フォント（英字は Comic Sans 系、日本語は丸ゴシック）。
- **レイアウト**: 各パズル = 1 画面完結。上部に問題文、中央にイラスト、下部に操作領域。
- **モバイルらしさの勘所**: 「手描き感」で親しみやすさを極大化。5.61M レビュー・4.7 星という実績が示すように、ゆるさが機能している。
- **取り込みポイント**: ブレインゴースト は真面目寄りのトーンだが、**結果画面の「やったね！」フィードバックや、空白時間のマイクロアニメ**（キャラがぴょこっと顔を出すなど）は Brain Test 的なコミカル演出を一点だけ入れると親しみが増す。
- **避けるべき点**: 全体を手描き調にすると「脳年齢」の真面目さと矛盾する。適用は結果画面のワンポイントに限定。
- **出典**: [Unico Studio 公式 Medium](https://medium.com/@unicostudio/unico-studio-and-the-rise-of-brain-test-d91db1da2836), [App Store](https://apps.apple.com/us/app/brain-test-tricky-puzzles/id1486214495)

## 参考にしたい画面 Top 5

1. **毎日脳トレ の ハンコカレンダー画面** — 月グリッド + 押印済みの日だけ和風スタンプ。これが継続の動機を丸ごと作っている。`stamp_calendar.tscn` の目標画像。
2. **PEAK の Brain Map 画面** — 7 カテゴリをカラーコード付きで可視化。ブレインゴースト のレーダーチャートはこれを 6 軸に縮めた構成で作る。
3. **みんなの脳トレ の ホーム画面** — 中央に「脳年齢を測る」大型ボタン + 6 ゲームのグリッド。シンプルさの手本。
4. **数字さがし のゲーム画面** — 上部 HUD + 画面全体盤面 + 下部空白。ブレインゴースト の同ジャンルゲームはこれをほぼ踏襲。
5. **PEAK の 結果画面** — スコア → カテゴリ別バー → ベストスコア比較 → CTA ボタンの縦 4 段レイアウト。ブレインゴースト の `overall_result.tscn` の骨格として最も近い。

## 不明点・追加調査が必要な項目

- **ソルティオ (eMotiv)**: Play Store ページの動的レンダリングに阻まれ、スクリーンショットの詳細がほぼ取得できなかった。実機インストール or 第三者レビュー記事を発見次第、色・レーダーチャート形状・ホーム構成を追加調査したい。
- **PEAK の日本語ローカライズ版**: 英語版スクリーンショットの描写は得られたが、日本語フォントでの組版がどう見えるかは不明。実機で確認推奨。
- **毎日脳トレ のハンコのデザイン詳細**: 朱色の丸印か、キャラクターものか、月替わりで変化するかなどの装飾ルールを実機で確認する必要がある。
- **みんなの脳トレ の結果画面グラフ**: 折れ線か棒か、軸の取り方が未確認。`individual_result.tscn` 設計前に実機スクショを撮りたい。
- **各アプリの余白・角丸ピクセル値**: ストアのスクショからでは正確な数値は取れない。Godot 実装時は Figma で当たりを付け、実機と比較調整する。
- **Brain Test の「結果画面マイクロアニメ」**: 採用を決めたが、具体的にどの瞬間にどのイージングで動かすかは別途アニメーション設計書で詰める必要あり。
