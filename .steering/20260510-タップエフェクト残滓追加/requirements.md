# 要求 — ゴースト7番勝負 タップエフェクトに残滓を追加

## 背景

ユーザから「瞬間タップのデザインをもっとおしゃれに実装できるか？promotion のエフェクトのように残滓を残すようにしたい」と要望あり。

参照: `docs/design/promotion/game_tap_touch.png`

## promotion との差分（タップ瞬間の演出）

| 要素 | 現状の実装 | promotion 目標 |
|---|---|---|
| 中央スターの放射 ray | 4 長軸 + 4 対角 = **8 本**（均等） | **24 本以上**、長さ・太さに揺らぎ（不揃い感） |
| リング | TapBurst の 7 リング、1100ms | OK、もう少し余韻があってもよい |
| ダスト粒子の残滓 | **なし** | 周囲に小粒のダストがじわっと浮かびフェード |
| 中央コア | 1100ms でフェード | OK |
| 全体の etheric 感 | やや硬質 | 柔らかく、空気感あり |

## 要件

1. タップ瞬間に **ダスト粒子**（promotion の余韻）を散布する新エフェクトを追加
2. YOU 側スターの ray を **24 本 + ジッタ** に強化（角度オフセット、長さ・太さの揺らぎ）
3. 既存の TapBurst / SideLaser はそのまま温存（多重に重ねる）
4. win/lose の hot/mid 色を残滓粒子にも継承（負けはグレー、PERFECT は gold、win は cyan）

## 制約

- GDD のネガ色禁止ルールは引き続き遵守（lose 時は赤を出さない）
- 1700ms 以内には完全に消える（次ラウンドの ready overlay と被らない）
- パーティクル数は 80 程度にとどめ、Web 版でも 60fps を維持

## 検証

- `tools/snap_g7_result.gd` で result phase をキャプチャし promotion と並べて目視比較
- snap timing を YOU が GATE 中心付近で tap するよう調整（67ms GREAT WIN シナリオなど）
