# 要求内容

## 概要

ホーム画面から遷移できる「脳トレ一覧画面」を作成する。6種のミニゲームをカルーセル形式で一覧表示し、任意のゲームを選んでプレイ開始できる。

## 背景

ミニゲームが3本（反射タップ・フラッシュ暗算・順番記憶）実装済みとなり、ホーム画面の能力グリッドからの直接起動だけでなく、全ゲームを一覧できる専用画面が必要になった。functional-design.md の状態遷移図で `Home → AllGameList → RuleExplain` の導線が定義されている。

## 実装対象の機能

### 1. 脳トレ一覧画面（AllGameList）
- Stitch「脳トレ一覧画面 (3Dカルーセル形式)」デザインを Godot に変換
- 6種のゲームカード（反射タップ / フラッシュ暗算 / 順番記憶 / 色文字テスト / 神経衰弱 / 数字さがし）
- カルーセル: 中央のカードが大きく、左右は縮小＋透過で奥行き表現
- 各カードに Material Symbols アイコン + ゲーム名 + 説明文 + ベストスコア
- ドットインジケーターで現在位置表示
- スワイプ（ドラッグ）と左右タップで切り替え
- 実装済みゲームをタップ → GameManager.start_game() で起動
- 未実装ゲームは COMING SOON バッジ表示

### 2. ホーム画面からの導線追加
- ボトムナビの「脳トレ」タブからGameList画面へ遷移
- GameListの「ホーム」タブからホーム画面へ戻る
- GameManager にルーティングメソッド追加

## 受け入れ条件

### 脳トレ一覧画面
- [ ] 6枚のゲームカードがカルーセル表示される
- [ ] 中央カードは拡大、隣接カードは縮小・透過で奥行き感がある
- [ ] ドラッグ操作でカードを左右に切り替えできる
- [ ] ドットインジケーターが現在位置を反映する
- [ ] 実装済み3ゲーム（reflex_tap, flash_calc, sequence_memory）をタップするとルール説明画面に遷移
- [ ] 未実装ゲームにはCOMING SOONバッジが表示される

### ナビゲーション
- [ ] ホーム画面のボトムナビ「脳トレ」タブで一覧画面に遷移する
- [ ] 一覧画面のボトムナビ「ホーム」タブでホーム画面に戻る

## スコープ外

- カルーセルの3D CSS transform完全再現（Godotでは2Dスケール+アルファで代替）
- ベストスコアの実データ連携（プレースホルダー表示、将来DataStore接続）
- 設定・分析・アワードタブの実装
