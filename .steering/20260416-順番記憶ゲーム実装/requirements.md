# 要求内容

## 概要

順番記憶ゲーム（短期記憶力）をStitchデザインに準拠して新規実装する。

## ゲームルール（GDD §4-2）

- N個のパネルが順番に光り、同じ順番でタップする
- 正解するたびに N+1（レベルアップ）
- 失敗したらゲーム終了
- スコア: maxReachedLevel × 150
- クリア系ゲーム（プレイ中ゴーストバー非表示、結果画面で比較）

## Stitchデザインの構成要素

### プレイ画面（stitch_play.png / HTML）
1. **ラウンド表示**: "ROUND 05" 青ピルバッジ
2. **指示テキスト**: "順にタップしてください" 超大文字
3. **3x3メモリーグリッド**: 9パネル、アクティブパネルは青+白番号表示、非アクティブは白+底シャドウ
4. **タイマー**: 右上に円形（残り秒数）
5. **ゴーストバトルバー**: 共有シーン（スコア比較）

### パネルのスタイル
- 通常: 白背景、底12pxシャドウ（#cbd5e1）、角丸2.5rem、1:1アスペクト比
- アクティブ（光る）: 青背景 #007BFF、底シャドウ #0056b3、青グロー、scale 1.05
- タップ時: translateY(6px)、底シャドウ4px

### ゲームフロー
1. 表示フェーズ: パネルが順番に光る（各0.5秒程度）
2. 入力フェーズ: ユーザーが同じ順番でタップ
3. 正解 → N+1 で次のラウンド
4. 不正解 → ゲーム終了

## 受け入れ条件

### ゲームロジック
- [ ] BaseGameを継承したSequenceMemoryクラス
- [ ] rng（決定論）でパネル光る順を生成
- [ ] レベル進行（初期3パネル → 正解でN+1）
- [ ] イベント記録（"level_cleared" / "level_failed"）

### プレイ画面UI
- [ ] 3x3グリッド（9パネル）
- [ ] 表示フェーズ: パネルが順番に青く光るアニメーション
- [ ] 入力フェーズ: タップで正誤判定
- [ ] ラウンド表示 + 指示テキスト
- [ ] タイマー表示

### 共有コンポーネント
- [ ] ルール説明: 既存rule_explain.tscnのRULES辞書で対応済み
- [ ] 結果画面: individual_resultのsequence_memory設定で対応済み
- [ ] ゴーストバトルバー: 共有シーン流用

## スコープ外

- パネル数の変動（3x3固定、v1.1で4x4を検討）
- サウンド効果（音声未実装）
