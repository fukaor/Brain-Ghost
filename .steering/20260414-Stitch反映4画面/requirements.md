# 要求内容

## 概要

Stitchで作成した4画面（ホーム、ルール説明、反射タップ プレイ、結果）のデザインを現在のGodot実装に反映する。

## 背景

Stitch上でUIデザインを反復改善し、最終版が決まった。現在のGodot実装とStitchデザインの差分を埋めて、ビジュアルを統一する。

## 実装対象の画面

### 1. ルール説明画面 (rule_explain)
Stitch: 「ルール説明：反射タップ (1080x1920 戻るボタン版)」

**Stitchデザインとの主な差分:**
- ヘッダーにゲームアイコン（⚡）+ タイトル + サブテキスト「脳力: 反応速度」を追加
- 戻るボタンを右上に配置（現在は左上）
- ゴーストキャラの下に TARGET/FAKE 説明カード2枚を追加
  - TARGET: 的をタップ！(青いターゲットアイコン付き)
  - FAKE: ✕は無視しよう（✕アイコン付き）
- 警告テキスト「⚠ フェイクをタップすると、タイムロスになるよ！」
- CTA ボタンのテキストを「脳トレ開始 ▶」に変更
- ルール説明テキストの内容をStitchに合わせて更新

### 2. 反射タップ プレイ画面 (reflex_tap)
Stitch: 「反射タップ：プレイ画面 (UIスリム化・エリア拡大版)」

**Stitchデザインとの主な差分:**
- HUDリデザイン: 3ピル → 左: CURRENT AVG (0.45s) / 中央: PROGRESS (7/20) / 右: 円形プログレス
- 背景を page_bg → page_bg_v2 に変更
- ターゲットのビジュアル強化（青い円 + 星型アイコン、グロー効果）
- 画面下部にゴーストバトルバー追加（自分 vs ゴースト のリアルタイムスコア比較 + LIVE SYNC バッジ）

### 3. 結果画面 (individual_result)
Stitch: 「反射タップ：結果画面 (レイアウト微調整版)」

**Stitchデザインとの主な差分:**
- レイアウト再構成: ゴーストキャラ+吹き出しを画面上部に移動
- メインスコアをスコア数値ではなく平均反応時間（0.42s）で大きく表示
- 「NEW BEST!」バッジ（黄色ラベル）
- YOU vs GHOST 比較セクション追加（VICTORYバッジ付き）
- パーフェクト/ミス回数の統計表示を追加
- ボタン構成変更: CTA「もう一度プレイ」+ テキストリンク「ホームに戻る」

### 4. ホーム画面 (home)
Stitch: 「ホーム画面 (吹き出ししっぽ隙間調整・最終版)」

**差分は軽微 — 現在の実装がほぼStitchに準拠済み:**
- CTAボタンにゴーストアイコン（👻）を追加
- 微調整のみ（大きな構造変更なし）

## 受け入れ条件

### ルール説明画面
- [ ] ヘッダーにゲームアイコン+サブテキスト（脳力名）が表示される
- [ ] TARGET/FAKE 説明カードが2列で表示される
- [ ] 警告テキストが表示される
- [ ] 戻るボタンが右上に配置されている
- [ ] CTA が「脳トレ開始 ▶」になっている

### 反射タップ プレイ画面
- [ ] HUDがStitchデザインに準拠（AVG, PROGRESS, 円形プログレス）
- [ ] 背景が page_bg_v2 になっている
- [ ] 画面下部にゴーストバトルバーが表示される

### 結果画面
- [ ] ゴーストキャラ+吹き出しが画面上部に表示される
- [ ] 平均反応時間が大きなフォントで表示される
- [ ] YOU vs GHOST の比較セクションがある
- [ ] パーフェクト/ミス統計が表示される
- [ ] CTA + テキストリンクのボタン構成

### ホーム画面
- [ ] CTAにゴーストアイコンが表示される

## スコープ外

- ゲームロジックの変更（スコア計算、タイミング等）
- 新しいゲームの追加
- データ連携の実装（脳年齢計算、ゴーストシステム等のTODOは既存のまま）
- テーマファイル(default_theme.tres)の大幅な変更（既存のtheme variationで対応）
- フラッシュ暗算画面のStitch反映（別タスク）
