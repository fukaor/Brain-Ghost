# 要求内容

## 概要

ホーム画面をStitchデザイン（v0.1）を視覚的な正としてGodot側のシーン・スクリプトを再作成する。仕様優先度は **Docs > Stitch > 現在の実装**。

## 背景

現在の実装はプロトタイプレベルで、StitchのデザインシステムThe Ethereal Pulseに基づいたv0.1デザインが完成した。キャラクターイメージやアイコン等はバージョンアップに伴い差し替わる可能性があるため、アセット参照を差し替え容易な構造にする。

## Stitch v0.1 デザイン構成（視覚的な正）

### レイアウト（上から順）
1. **ヘッダー行**: 脳年齢パネル（左）+ ゴーストバトル戦績パネル（右）
2. **ゴーストキャラ + 吹き出し**: 中央に半透明精霊キャラ、吹き出しでセリフ
3. **能力分野カード**: 6つの能力アイコン（計算/記憶/注意/反応/観察/判断）
4. **CTAボタン**: ピル型グラデーション「今日の脳トレを開始する」
5. **ボトムナビ**: 5タブ（脳トレ/分析/ホーム/アワード/設定）

### デザインシステム
- 背景: ライトブルー〜ホワイトのグラデーション
- カード: グラスモーフィズム（白85%背景、角丸、拡散影）
- ボーダー禁止（トーン差で区切る）
- 赤色禁止（負けはグレー系）

## 受け入れ条件

### レイアウト・ビジュアル
- [ ] Stitch v0.1と同等のレイアウト構成
- [ ] デザインシステム「The Ethereal Pulse」準拠（グラスモーフィズム、ボーダー禁止、赤色禁止）
- [ ] キャラ画像・アイコンがテクスチャパスの変更のみで差し替え可能

### Docs仕様準拠
- [ ] 脳年齢に暫定/確定表記が反映される
- [ ] ストリーク表示が存在する
- [ ] 条件付きバナー（年代設定/復帰演出）の表示領域がある
- [ ] 広告エリアが最下部に存在する（Android時のみ表示）
- [ ] ゴーストキャラの不透明度が精度に連動する

### 機能
- [ ] CTAボタンで脳トレ開始（GameManager.start_daily_challenge）
- [ ] 能力セルタップでゲーム直接開始（実装済みゲームのみ）
- [ ] ボトムナビ5タブが機能する（遷移先未実装はprint stub）
- [ ] DataStoreからの実データ読み込み（接続済み部分のみ）

## スコープ外

- ボトムナビの遷移先画面の実装（脳トレ/分析/アワード/設定）
- ゴーストキャラの表情バリエーション（v1.1）
- ハンコカレンダーUI（別タスク）
- DataStore/GhostSystemの新規実装（既存のものを接続するのみ）
