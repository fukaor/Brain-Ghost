# 要求内容

## 概要

フラッシュ暗算ゲーム（計算力）をStitchデザインに準拠して新規実装する。ロジッククラス + ビュー + tscn の3層構成。

## 背景

GDD §4-1 に定義されたミニゲーム2番目。反射タップに続き「これだけでも楽しい」を成立させる重要ゲーム。テンキー入力UIが特徴。

## ゲームルール（GDD §4-1）

- 画面に数字が次々と表示され、合計を回答
- 制限時間: 30秒
- パラメトリック要素: 数字の桁数・演算子（＋/−混合）
- テンキー入力（選択式ではない）
- 正答1問=100点 + 残り秒数×10

## Stitchデザインの構成要素

### プレイ画面（stitch_play.png / HTML）
1. **計算表示エリア**: "23 - 12" 超大文字（280px HTML）、青=数字、赤=マイナス
2. **回答表示**: "???" → ユーザー入力に連動
3. **タイマー**: 右上に円形プログレス（残り秒数表示）
4. **ゴーストバトルバー**: 共有シーン（自分 vs ゴースト 正解数比較）
5. **テンキーパッド**: 3x4グリッド（1-9, backspace, 0, confirm）、glass-cardの中

### ルール説明画面（stitch_rule.png）
- 既存のrule_explain.tscnパターンを流用
- タイトル「フラッシュ暗算」、制限時間30秒、演算例、テンキープレビュー

### 結果画面
- 汎用 individual_result.tscn をそのまま使用（score_format: "int", stat: 正解/誤答）

## 受け入れ条件

### ゲームロジック
- [ ] BaseGameを継承したFlashCalcクラス
- [ ] 30秒タイマーで自動終了
- [ ] rng（決定論）で問題を生成（＋/−混合、桁数パラメトリック）
- [ ] 正答/誤答イベント記録（"correct" / "wrong"）
- [ ] スコア算出: correctCount * 100 + remainingSec * 10

### プレイ画面UI
- [ ] Stitch準拠のレイアウト（計算表示 + 回答 + タイマー + バトルバー + テンキー）
- [ ] テンキー入力→回答表示→確定→正誤判定→次の問題
- [ ] タイマー円形プログレス（30秒カウントダウン）
- [ ] ゴーストバトルバー（共有シーン流用）

### ルール説明画面
- [ ] 既存rule_explain.tscnのデータを拡張してフラッシュ暗算対応

### 結果画面
- [ ] individual_result の flash_calc 設定で正しく表示される

## スコープ外

- 難易度の動的調整（v1.1以降）
- 掛け算・割り算（GDDに記載なし）
- ルール説明画面のtscn新規作成（既存パターンのデータ拡張で対応）
