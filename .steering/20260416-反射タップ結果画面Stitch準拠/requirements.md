# 要求内容

## 概要

反射タップゲームの個別結果画面（`scenes/ui/individual_result.tscn`）をStitchデザインに準拠して新規作成する。

## 背景

反射タップのプレイ画面が完成し、次に必要なのはゲーム終了後の結果表示画面。Stitchで「反射タップ：結果画面 (レイアウト微調整版)」が作成済み。全ゲーム共通の個別結果画面として使い回せる汎用設計とする。

## Stitchデザインの構成要素（上から順）

### 1. キャラクター＋吹き出しエリア
- 左: ちびキャラ精霊（280x280、浮遊アニメ）
- 右: 吹き出し「すごい！昨日より反応が速くなってるよ！」
- 吹き出しは白背景・角丸・左下にしっぽ

### 2. メインスコアカード（premium-trophy-card）
- 背景: 半透明白グラデーション、白ボーダー、大きなシャドウ
- 上部: stars アイコン + "RESULTS" ラベル + stars アイコン
- 中央: "0.42s" 特大スコア（180px HTML）+ "NEW BEST!" バッジ（右上に傾き）
- 下部: "平均反応時間" キャプション

### 3. ゴーストバトルカード（glass-panel）
- 左: "YOU" ラベル + "0.42s" スコア
- 中央: "VICTORY" バッジ（緑背景）
- 右: "GHOST" ラベル + "0.45s" スコア
- 下部: プログレスバー（自分 58% : ゴースト 残り）

### 4. 統計グリッド（2カラム）
- 左カード: "パーフェクト" + "18回"
- 右カード: "ミス" + "2回"（エラー色）

### 5. アクションボタン
- "もう一度プレイ" 青CTAボタン（replay アイコン、押し込みシャドウ）
- "ホームに戻る" 白セカンダリボタン（home アイコン）

## 受け入れ条件

### UI構造
- [ ] Stitchデザインの5セクション全てが表示される
- [ ] 放射グラデーション背景（他画面と統一）
- [ ] テキストサイズはスマホ視認性を考慮（キャプション12px以上）

### データ連携
- [ ] GameManagerからPlayLogを受け取りスコア表示
- [ ] ゴースト対戦結果（勝敗・スコア比較）を表示
- [ ] パーフェクト/ミス回数を表示

### 共有テーマの活用
- [ ] 既存テーマvariation（glass_bubble, headline_v2, caption_v2等）を活用
- [ ] 新規スタイルはdefault_theme.tresに追加

### 画面遷移
- [ ] "もう一度プレイ" → 同じゲームを再プレイ
- [ ] "ホームに戻る" → ホーム画面に遷移

## スコープ外

- 総合結果画面（overall_result.tscn）は別タスク
- シェアURL生成機能は別タスク
- ゴーストキャラクターの精霊画像アセット追加（既存のghost_seirei.pngを使用）
- ストリーク・脳年齢表示
