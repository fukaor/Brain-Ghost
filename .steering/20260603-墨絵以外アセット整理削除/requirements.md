# 要求: 墨絵ブランド以外のアセット整理・削除

## 背景
墨絵テーマ (Sumi Ghost v4) リブランド後、旧デザインシステム（グラスモーフィズム系）・旧キャラ探索・置換済みの汚染パーツ・重複デザインツリーが `assets/` と `docs/` に大量に残存し、「直す対象が多すぎる」状態。現行 sumi ビルドが実際に使うアセットはごく少数。

## ゴール
**現行 sumi_theme が実使用するアセット＋法的必須ファイルだけを残し、それ以外の死蔵データを削除して見通しを良くする。**

## スコープ
- 対象: `assets/` 配下の未参照・旧デザイン・汚染パーツ、および `docs/design/claude_design/` の重複デザインツリー。
- 非対象: `scripts/` `scenes/` のコード、`addons/gut/`（テストFW・別件）、`docs/ideas/sumi-theme/`（デザイン原本＝残す）。

## 制約・前提
- **削除前に必ず参照0を再確認**（substring衝突に注意。例: `washi_base` は `bg_washi_base` と衝突する）。
- 全候補は git 追跡済み → 誤削除は `git restore` で復元可能（コミット前なら確実）。
- `.png` 削除時は対の `.import` / `.uid` も削除。
- 削除後に **import が通り / home 実起動キャプチャが出て / GUT 82 が緑** であることを必ず確認。
- CREDITS.md / repository-structure.md の更新が要る場合は doc 承認フローに従う。
- 本作業は独立コミット（例: `chore: 墨絵以外の死蔵アセット削除`）にまとめる。

## 完了条件
- 死蔵アセット削除後、`godot --headless --import` がエラーなし、home 実起動キャプチャ正常、GUT 82/82。
- 残ったアセットがすべて「現行 sumi で使用 or 法的必須 or 構造プレースホルダ」だけになっている。
