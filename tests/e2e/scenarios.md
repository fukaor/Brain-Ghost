# ブレインゴースト — E2E テストシナリオ（手動）

MVP では E2E テストを自動化せず、本ファイルのチェックリストに沿って手動で実施する。Week 4 のリリース前に全シナリオをパスすること。

---

## 前提

- Android 実機 3 機種（例: Galaxy A, Pixel, Xperia ミドル）
- Chrome モバイル（DevTools デバイスモードでも可）
- テスター用 AdMob ID を `export_presets.cfg.local` に設定済み
- Google Play Console にテスター登録済み

---

## E2E-01: 初回オンボーディング完走

**手順**:
1. アプリ初回起動
2. 「あなたの脳力を測定します」イントロ（2 秒）が表示される
3. 反射タップのルール説明 → カウントダウン → ゲーム実施
4. 個別結果画面で「続ける」をタップ → 次の種目へ
5. 全 6 種を順に完走
6. 正式結果画面で脳年齢・レーダーチャートが表示される
7. [ホームへ] でホーム画面に遷移

**合格条件**:
- [ ] 全 6 種がクラッシュなく完走できる
- [ ] 精度が 17% → 33% → ... → 100% に増えていく
- [ ] 精度 < 100% の間はゴースト対戦とレーダーチャートがロック表示
- [ ] 精度 100% で確定演出とレーダーチャート解放演出が出る
- [ ] 脳年齢表示に「エンターテインメント目的」の注記がある

---

## E2E-02: デイリーチャレンジ完走 + 広告確認

**手順**:
1. ホームから [今日のチャレンジ] をタップ
2. 日付シードで選ばれた 3 種をプレイ
3. 総合結果画面 → [ホームへ] で戻る
4. 以上を 3 回繰り返す（インタースティシャル広告が 1 回出ればOK）

**合格条件**:
- [ ] 3 種が約 2 分で完走できる
- [ ] プレイ中に広告が一切出ない
- [ ] ゲーム間に広告が挟まらない
- [ ] 総合結果 → ホームの遷移で 3 回に 1 回インタースティシャル広告が出る
- [ ] ホーム画面下部にバナー広告が常時表示される

---

## E2E-03: 広告非表示買い切り購入 → 再起動後の復元

**手順**:
1. 設定画面 → [広告を非表示にする（¥400）] をタップ
2. Google Play の購入フローで「テスト購入」を完了
3. 購入完了画面で感謝演出が表示される
4. アプリを完全終了 → 再起動
5. ホーム画面 → デイリー 3 種完了 → インタースティシャル出ないことを確認

**合格条件**:
- [ ] 購入後、ホームのバナー広告が消える
- [ ] 再起動後も `hasPurchasedAdFree` が保持されている
- [ ] `queryPurchasesAsync()` がアプリ起動時に実行される
- [ ] リワード広告も表示されない（または「広告非表示中です」的な置換）

---

## E2E-04: Web版シェアURL経由プレイ

**手順**:
1. Web版で総合結果画面から [シェア] をタップ
2. 生成された URL をコピー（`brain.reigals.com/daily?d=20260415&s=3230`）
3. 別ブラウザセッションで URL を開く
4. 「ねこぽのスコア: 3,230pts。勝てる？」が表示される
5. [挑戦する] をタップ → 同じ日付シードで 3 種プレイ
6. プレイ後にスコア比較が表示される

**合格条件**:
- [ ] シェア URL から同じデイリー 3 種が始まる
- [ ] OGP カードが X / LINE で正しく表示される
- [ ] 比較表示にシェア元のスコアと自分のスコアが並ぶ

---

## E2E-05: Web版の音声自動再生制限回避

**手順**:
1. Chrome / Safari で Web版を開く
2. 起動直後は音声が鳴らないことを確認
3. 任意の画面をタップ
4. タップ後に BGM / SE が鳴ることを確認

**合格条件**:
- [ ] 起動時のスプラッシュでは音声が鳴らない
- [ ] 最初のユーザータップ後に AudioServer が有効化される
- [ ] DevTools のコンソールに音声関連のエラーが出ない

---

## E2E-06: 複数機種でのクラッシュ・FPS 確認

**手順**:
1. Android 実機 3 機種でそれぞれ以下を実施:
   - オンボーディング → ホーム → デイリー 3 回 → 設定画面 → ホーム
2. Godot Monitor（またはログ）で FPS を記録
3. クラッシュログ（`logcat`）を確認

**合格条件**:
- [ ] 全 3 機種でクラッシュが発生しない
- [ ] プレイ中は 60fps を維持する
- [ ] ロード時間が 3 秒以内（Galaxy A シリーズ）

---

## E2E-07: ストリーク境界値テスト（端末時刻操作）

**手順**:
1. 端末時刻を 2026-04-10 に設定してプレイ（ストリーク 1）
2. 端末時刻を 2026-04-17（7 日後）に進めて再プレイ
3. ホームに「おかえりなさい！ストリーク 2 日 継続中」と表示されることを確認
4. 端末時刻を 2026-04-25（8 日後）に進めて再プレイ
5. ホームに復帰演出が出ず、ストリークが 1 にリセットされることを確認

**合格条件**:
- [ ] 7 日空きでストリークが維持され、復帰演出が 1 度だけ表示される
- [ ] 8 日空きでストリークが 1 にリセットされ、復帰演出が出ない
- [ ] リセット時にどこにも赤色（警告色）が使われない

---

## 総合合格基準

上記 7 シナリオが全て合格することで MVP リリース準備完了とする。
