# 脳トレアプリ UI/UX デザインガイド

Lumosity・Peak・Elevate等の主要脳トレアプリの調査に基づく、UI/UXデザイン判断のためのリファレンス。
新機能の設計やデザインレビュー時に参照する。

## 1. ホーム画面の設計原則

### 1.1 CTAは1つに絞る

全主要アプリ共通: ホーム画面のプライマリCTAは「今日のトレーニング」の1つだけ。
77%のユーザーが初回使用後に離脱するため、選択肢を増やすほど離脱率が上がる。

```
✅ 正しい設計:
   [今日の脳トレを開始する] ← 大きいCTA 1つ
   得意分野グリッド ← 補助的な情報表示

❌ 避けるべき設計:
   [反射タップで遊ぶ] [フラッシュ暗算で遊ぶ] [順番記憶で遊ぶ] ← 選択肢が多い
```

### 1.2 情報密度のバランス

脳トレアプリは「シンプルすぎる（退屈）」と「複雑すぎる（認知負荷が高い）」の中間が最適。
カード型レイアウト、段階的開示、明確な視覚的ヒエラルキーで情報を整理する。

### 1.3 主要アプリのホーム画面構成

| アプリ | 構成 | 特徴 |
|--------|------|------|
| Lumosity | カード型、Material Design風 | プログレスドット、セッションフロー明確 |
| Peak | カラフル、アニメーション多め | 「Coach」推奨、「Coffee Break」モード |
| Elevate | 洗練、プロフェッショナル | 推奨ワークアウトパスを提示、選択肢を絞る |

## 2. スコア・進捗の可視化

### 2.1 スコアリングシステムの設計

| 方式 | メリット | デメリット | 例 |
|------|---------|-----------|-----|
| 複合スコア (LPI) | 全体像が掴める | 算出根拠が不透明だと不信感 | Lumosity |
| 3階層スコア | 粒度の異なる理解が可能 | UI設計が複雑 | Lumosity (ゲーム/能力/総合) |
| 脳年齢 | 直感的、個人的で刺さる | 科学的根拠への疑問 | CogniFit, ブレインゴースト |
| 能力マップ | 強み/弱みが一目瞭然 | 小画面で表示しにくい | Peak (Brain Maps) |

**ブレインゴーストへの適用:**
- 脳年齢 = メインのフック（直感的で個人的）
- 6能力ドーナツ円 = 能力マップの簡略版
- ゴースト対戦 = 独自の比較軸（競合にない）

### 2.2 可視化手法の使い分け

| 手法 | 用途 | 最適な場面 |
|------|------|-----------|
| 折れ線グラフ | 時系列の推移 | 分析画面、月次レポート |
| レーダーチャート | 能力バランス | 総合結果画面（精度100%時） |
| ドーナツ円 | レベル表示 | ホーム画面の能力グリッド |
| プログレスバー | 完了度 | セッション進捗、デイリー目標 |
| カレンダー | 継続性 | ストリーク表示、ハンコカレンダー |
| 比較メトリクス | 相対評価 | ゴースト対戦結果 |

### 2.3 脳年齢の表示ルール

- CogniFitが「認知年齢 vs 実年齢」の比較UIを採用 → ブレインゴーストも同じアプローチ
- 初回は甘めに補正（3〜5歳若く）→ 即座にポジティブ体験
- 「娯楽目的」の注記は設定画面に移動し、ホーム画面には出さない

## 3. 色彩設計

### 3.1 色の心理学的効果

| 色 | 効果 | 用途 |
|------|------|------|
| **青** | 信頼、冷静、専門性 | 背景、情報画面、プライマリカラー |
| **緑** | 安全、成長、成功 | 勝利・改善の表示 |
| **紫** | 知性、創造性 | ブランディング（脳トレと相性良い） |
| **オレンジ/黄** | エネルギー、楽観 | CTA、励ましのメッセージ |
| **グレー** | 中立、非批判的 | 未改善状態（ネガティブ色の代替） |
| **赤** | 使用禁止 | ブレインゴーストのルール: 負けてもネガティブ色を使わない |

### 3.2 デザイントレンド (2025-2026)

- **エモーショナルミニマリズム**: 柔らかい色のグラデーション、繊細なテクスチャ、表現力のあるタイポグラフィ
- **グラデーション背景**: 奥行き感をクラッターなしで演出
- **マイクロシャドウ**: 現代的な深みの表現（スキューモーフィズムではなく）
- **ダークモード**: 主流トレンドだが、脳トレでは未採用アプリも（Peak等）

## 4. ネガティブ結果の扱い方（最重要）

### 4.1 絶対ルール

- **赤色を使わない**（ブレインゴースト既存ルール）
- **「失敗」「負け」の言葉を使わない**
- **機会としてフレーミングする**: 「改善の余地が見つかった」
- **スナップショットでなく軌跡を見せる**: 単発の結果ではなくトレンドライン
- **具体的なアクションを提示**: 「次はXに集中してみよう」で主体性を与える

### 4.2 結果別の演出ヒエラルキー

| 結果 | ビジュアル | サウンド | メッセージのトーン |
|------|-----------|---------|----------------|
| 自己ベスト更新 | 紙吹雪/花火 (300-500ms) | 勝利のサウンド | 「新記録！すごい！」 |
| ゴーストに勝利 | 金/緑ハイライト | 成功チャイム | 「昨日の自分に勝った！」 |
| 改善したがゴーストに未勝利 | 控えめなポジティブアニメ | 穏やかなポジティブ音 | 「もう少し！」 |
| 改善なし | ニュートラル、アニメなし | ニュートラル/無音 | 「続けることが大事だよ」 |
| 初回プレイ | 励ましアニメ | 歓迎のサウンド | 「いいスタート！基準値が設定されたよ」 |

### 4.3 ゴースト対戦での表現

```
✅ 良い表現:
   「今日のゴーストは強かった！」（ゴースト側を称える）
   「次はきっと超えられるよ」（将来への期待）

❌ 避ける表現:
   「あなたの負けです」（直接的な敗北宣告）
   「スコアが下がりました」（ネガティブなフレーミング）
```

## 5. ゲーミフィケーション

### 5.1 ストリーク

| 要素 | ベストプラクティス | データ |
|------|----------------|------|
| 7日間の壁 | 7日連続達成ユーザーの長期継続率は3.6倍 | Duolingo |
| 回復メカニズム | 「ストリーク凍結」で離脱を21%削減 | Duolingo |
| マイルストーン報酬 | 3, 7, 30, 100日で特別バッジ | 複数アプリ |
| ウィジェット表示 | ホーム画面ウィジェットで継続コミットメント60%増 | Duolingo |

**ブレインゴーストへの適用:**
- ハンコカレンダー = 加算型（スタンプを得る）で、罰則型（進捗を失う）ではない
- ストリーク凍結は将来的に実装検討

### 5.2 報酬設計

- 毎回のゲーム後にポイント → 即時フィードバック
- 変動報酬（予測不能な報酬）は固定報酬よりドーパミン反応が強い
- デイリーチャレンジはDAUを25%増加（Duolingo）
- バッジ/実績は完了率を30%向上

### 5.3 適応的難易度

フロー状態の維持が核心:
- 簡単すぎる → 退屈 → 離脱
- 難しすぎる → フラストレーション → 離脱
- 適切なチャレンジ → フロー → 継続

## 6. オンボーディング

### 6.1 タイミングの科学

| 時間 | ユーザーの状態 |
|------|-------------|
| 0.2秒 | 感情的印象が形成される |
| 3秒 | 認知的印象が形成される |
| 10-30秒 | 残留/離脱の判断がされる |
| 2回の連続した意思決定 | 精神的疲労が始まる |
| フォームフィールド1つ追加ごと | 離脱率12-18%増加 |

### 6.2 ベストプラクティス

1. **30秒以内に価値を提供**: 何かを聞く前にまず遊ばせる
2. **プログレッシブプロファイリング**: 最小限のデータを今、残りは信頼構築後に
3. **数分以内に「初勝利」**: 意味のある結果を素早く届ける
4. **1画面あたり最大3アクション**: 認知的過負荷を防ぐ
5. **目標設定は投資を生む**: 「何を改善したい？」で commitment が生まれる
6. **ベースライン評価をゲームプレイとして**: 初回テストを最初のゲームとしてフレーミング
7. **パーソナライゼーションを即座に見せる**: 「あなたの結果に基づいたプラン」

### 6.3 ブレインゴースト固有

- ゴーストコンセプトを早期に紹介（競合との差別化ポイント）
- 年代設定 → 脳年齢キャリブレーション
- 1つのミニゲームを即座にプレイ → ベースライン
- 初回脳年齢を「3-5歳若め」補正で表示 → ポジティブ体験
- ゴーストは十分なデータ蓄積後に出現と説明

## 7. セッション設計

### 7.1 最適なセッション長

| アプリ | 推奨セッション | 構成 |
|--------|-------------|------|
| Lumosity | 15分 | 1日5ゲーム |
| Elevate | 5-10分/ゲーム × 3-5ゲーム | スキル別グループ |
| Peak | 2-3分（Coffee Break）〜フルワークアウト | 柔軟な長さ |
| **ブレインゴースト** | **2分** | 「毎日2分、昨日の自分に挑め」 |

### 7.2 設計原則

- **2分の最小セッション**: 習慣形成に最適（ブレインゴーストのコンセプトと一致）
- **頻度 > 持続時間**: マイクロセッションの方がマラソンセッションより継続率が高い
- **可変セッション**: 「クイックプレイ」(1-2ゲーム) と「フルワークアウト」(全ゲーム) を提供

## 8. マイクロインタラクション・アニメーション

### 8.1 タイミングガイドライン

| アクション | 時間 |
|-----------|------|
| ボタン押下フィードバック | 即時 (< 100ms) |
| 状態遷移 | 200-300ms |
| 成功演出 | 300-500ms |
| ローディング/プログレス | 連続的な動き |
| 重要マイルストーン演出 | 最大1000ms + パーティクル |

### 8.2 原則

- 成果が大きいほどアニメーションも大きく
- 小さな勝利 = 控えめな承認、大きなマイルストーン = 華やかな演出
- reduced-motion設定を常に尊重
- モバイルパフォーマンスを考慮したパーティクル数
